# KegManager
This is to track your kegs progress as you pour beers giving you an idea how much is left in your keg.

## Run locally with Flask

Install Flask if it is not already installed:

```bash
python -m pip install Flask
```

Start the web server from this directory:

```bash
python app.py
```

The site will be available at `http://localhost:5002`. To access it from
another device on your local network, use the Raspberry Pi's IP address, for
example `http://192.168.1.10:5002`.
